## 🚀 Featured Projects

### 🚗 [Connected Intelligence](https://github.com/Shruvexxx) 
**Vehicle Recognition & Tracking System** | *Sponsored by Parabola9*

Multi-object vehicle detection and tracking pipeline combining **YOLOv5**, **DeepSORT**, and **PaddleOCR** for real-time CCTV analysis.

**Tech Stack:** `YOLOv5` `DeepSORT` `PaddleOCR` `OpenCV` `Python`

**Key Features:**
- 🎯 Real-time multi-vehicle detection with re-identification
- 🔍 License plate OCR with preprocessing (Gaussian denoising, CLAHE, perspective correction)
- 🧹 Data deduplication using IoU-based association & appearance embeddings
- 📊 Trajectory tracking across video frames

**Impact:** Achieved robust tracking on low-quality CCTV feeds with minimized false positives.

### ⚖️ [LexiLight](https://github.com/Shruvexxx)
**Local Legal-Text Simplifier & RAG Pipeline**

Retrieval-Augmented Generation system that converts legal PDFs into plain-language summaries with grounded citations.

**Tech Stack:** `LangChain` `FastAPI` `Next.js` `RAG` `Embeddings`

**Key Features:**
- 📚 PDF ingestion → chunking → vector embeddings → retrieval
- 💬 Chat-based Q&A with source citation
- 🎨 Modern Next.js UI for document upload and interaction
- ✅ Quality assurance via Playwright, Pytest, ESLint, Prettier, Ruff, Black

**Impact:** Democratizes legal document understanding for non-experts.
